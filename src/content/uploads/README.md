# 문서 본문에 넣는 사진

편집 화면(`/admin/`)에서 **문서**의 본문에 사진을 넣으면 이 폴더에 올라옵니다.

## 왜 `src/assets` 가 아니라 여기인가

Astro 는 마크다운 안의 사진을 **문서 파일 기준 상대경로**로 적었을 때만 최적화합니다
(크기 줄이기, WebP 변환, width·height 자동 삽입). 편집 화면은 경로를 계산하지 못하고
고정된 문자열 하나만 붙일 수 있습니다.

문서는 전부 `src/content/{묶음}/파일.md` 로 깊이가 같으므로, 이 폴더를 문서 옆에 두면
`../uploads/사진.jpg` 라는 **하나의 고정 상대경로**가 모든 문서에서 그대로 맞습니다.
`src/assets` 에 두면 문서마다 다른 상대경로가 필요해져 편집 화면이 처리할 수 없습니다.

화면(홈·제품 등)에 쓰는 사진은 `src/assets` 에 그대로 둡니다 — 그쪽은 코드가 경로를
해석하므로 이 제약이 없습니다.
